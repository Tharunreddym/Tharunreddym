## About

I am a Formal Verification and Design Verification Engineer with an MEng in Computer Engineering from the University of Cincinnati. My work combines SystemVerilog Assertions, SymbiYosys formal verification, UVM-based pre-silicon verification, and low-power SoC validation.

For my RV32I CPU project, I built five formal harnesses with 31 assertion checks and 18 cover properties, using SymbiYosys, Yosys, and Boolector. The five proof tasks and five cover tasks pass in GitHub Actions. I also develop UVM environments for AXI4 and SRAM controllers and work on PMU state-transition verification at MediaTek.

My embedded validation background includes Bosch ECU interface testing across CAN, UART, SPI, and I2C, Python/pytest regression automation, and STM32/FreeRTOS validation.

I am interested in Formal Verification, ASIC/SoC Design Verification, CPU and memory-subsystem verification, and low-power verification roles.
